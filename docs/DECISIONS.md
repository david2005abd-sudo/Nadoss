# DECISIONS — NADOS

## ADR-001: Next.js App Router
- القرار: Next.js 14 + TypeScript + Tailwind.
- السبب: واجهة واحدة مع صفحات خادمية وواجهات API عند الحاجة.

## ADR-002: Supabase PostgreSQL + RLS
- القرار: قاعدة مشتركة مع tenant_id وسياسات Row Level Security.
- السبب: تقليل التعقيد مع عزل البيانات على مستوى قاعدة البيانات.
- شرط: لا يُعتمد على إخفاء عناصر الواجهة لحماية البيانات؛ اختبارات RLS إلزامية.

## ADR-003: لا تكاملات وهمية
- القرار: إبقاء الدفع والتوصيل والرسائل غير مفعلة حتى الحصول على مفاتيح وتوثيق رسمي.
- السبب: منع إيهام المستخدم بأن خدمة خارجية تعمل دون اتصال حقيقي.

## ADR-004: واجهة عربية أولًا
- القرار: RTL وتنسيق أسعار IQD.
- السبب: المنتج موجه للتجار في العراق.
