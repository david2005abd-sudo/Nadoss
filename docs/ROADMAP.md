# خارطة طريق NADOS

## المرحلة الحالية
المستودع يحتوي على وحدات المنصة الأساسية: مصادقة الهاتف/OTP، واجهة متجر، كتالوج وسلة وcheckout، إدارة المنتجات والطلبات والعملاء، adapters للتوصيل، WhatsApp + AI extraction، اشتراكات، دعم ومعرفة، metrics، وحجوزات.

## ما قبل الإطلاق
1. مراجعة نتيجة GitHub Actions لفرع fix/ci-supabase-validation؛ لا يُعلن نجاح البناء قبل ظهور checks خضراء.
2. تطبيق migrations 00001–00020 على Supabase staging والتحقق من RLS وسياسات القراءة العامة.
3. اختبار storefront والcheckout وRPC إنشاء الطلب ذريًا، بما في ذلك المخزون المتزامن وفشل بوابة الدفع.
4. اختبار التسجيل وOTP واستعادة كلمة المرور على مزود SMS حقيقي في staging.
5. اختبار RLS السلبي بين متجرين، الدفع، webhooks، التوصيل، WhatsApp، وحالات الفشل.
6. مراجعة كل تكامل يحتاج مفاتيح حقيقية؛ لا تعتبره متصلًا قبل اختبار مزود الخدمة.
7. نشر preview، اختبار الموبايل وRTL وإمكانية الوصول، ثم إعداد النسخ الاحتياطي والمراقبة.
8. بعد اجتياز كل ما سبق فقط، استكمال docs/LAUNCH_CHECKLIST.md ونشر الإنتاج.
