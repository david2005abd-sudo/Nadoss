# CHANGELOG.md

## [0.1.0] — 2026-10-16 🚀

### أُضيف — النسخة الأولى القابلة للنشر

**التطبيق (Next.js 14 + TypeScript + Tailwind):**
- صفحة هبوط عربية RTL كاملة: hero، 6 ميزات، 4 خطط أسعار، أسئلة شائعة، CTA
- مصادقة كاملة: تسجيل/دخول/استعادة كلمة المرور برقم هاتف عراقي (+964)
- لوحة تحكم التاجر: نظرة عامة بإحصائيات حية، منتجات (بحث + فلاتر)، طلبات (فلاتر حالات)، إعدادات
- واجهة متجر عامة `/store/[slug]` تعرض منتجات التاجر
- Middleware حماية مسارات مع توجيه ذكي
- API صحة `/api/health` يفحص التطبيق وقاعدة البيانات (503 عند فشل)
- تدهور رشيق: رسائل عربية واضحة عند عدم تهيئة قاعدة البيانات بدل الانهيار

**قاعدة البيانات (Supabase/PostgreSQL):**
- 6 ملفات migrations: 22 جدولًا كامل
- RLS على كل جدول متعدد المستأجرين + سياسات anon للمتجر العام
- Trigger: إنشاء متجر + اشتراك مجاني + عدّادات تلقائيًا عند التسجيل
- 5 RPCs ذرية: خصم مخزون، عدّادات، فحص مواعيد، إحصائيات عملاء
- Seed: 18 محافظة عراقية + 7 شركات توصيل + 4 خطط اشتراك بحدود واعية لتكلفة WhatsApp

**البنية:**
- GitHub Actions CI (type check + build)
- vercel.json للنشر
- .env.example موثق بالعربية
- README بشرح نشر كامل خطوة بخطوة

### الإصلاحات أثناء البناء
- استبدال `useActionState` (React 19) بـ `useFormState` (متوافق مع React 18 + Next 14)
- تصحيح أنواع cookies في عملاء Supabase SSR
- رفع حد ذاكرة البناء للبيئات المحدودة
