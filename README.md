# نادوس | NADOS

منصة SaaS عربية موجهة للتاجر العراقي لإدارة المتاجر والمنتجات والمخزون والطلبات والتوصيل، مع خارطة طريق للحجوزات والمساعد الذكي.

> **الحالة الحالية: تأسيس أولي.** الصفحة الرئيسية ولوحة التحكم واجهات معاينة ببيانات توضيحية. لم يتم تفعيل المصادقة أو CRUD أو الدفع أو WhatsApp أو شركات التوصيل. لا تستخدمها بعد لإدارة بيانات حقيقية.

## التقنية
- Next.js 14 App Router + React 18 + TypeScript
- Tailwind CSS + Lucide React
- Supabase PostgreSQL/Auth/Storage مخطط للتكامل
- RTL عربي وأسعار بالدينار العراقي
- GitHub Actions: typecheck, lint, build

## التشغيل المحلي
يتطلب Node.js 20.

```bash
npm install
cp .env.example .env.local
npm run dev
```

ثم افتح http://localhost:3000. الواجهة الأولية تعمل دون إعداد Supabase.

## أوامر التحقق
```bash
npm run typecheck
npm run lint
npm run build
```

## قاعدة البيانات
المخطط الأولي موجود في `supabase/migrations/00001_core_schema.sql` ويشمل المتاجر والعضويات والتصنيفات والمنتجات والعملاء والطلبات والمحافظات وسياسات RLS. **وجود migration في GitHub لا يعني تطبيقه على Supabase**؛ اختبره في مشروع تجريبي أولًا، ثم اختبر عزل متجرين قبل ربط الواجهة.

## خارطة الطريق
1. مراجعة CI وSQL على Supabase تجريبي.
2. Supabase Auth وإنشاء متجر وعضوية بشكل آمن.
3. CRUD المنتجات والتصنيفات والمخزون.
4. إدارة الطلبات والعملاء وواجهة متجر عامة.
5. تكاملات توصيل ودفع رسمية بعد التحقق من التوثيق والحسابات.
6. WhatsApp Cloud API مع التحقق من Webhook ومراجعة الطلبات المستخرجة.
7. الاشتراكات، الدعم، الحجوزات، الاختبارات والمراقبة.

## الأمان
- لا ترفع أسرارًا أو ملفات `.env` إلى Git.
- لا تكشف Service Role Key للمتصفح.
- لا تعتمد على الواجهة كحاجز أمني؛ RLS واختبارات عزل المستأجرين إلزامية.
- لا تدّعِ أن دفعًا أو توصيلًا أو رسالة خارجية تعمل قبل اختبار تكاملها الحقيقي.

راجع مجلد `docs/` للحالة والقرارات والقاعدة والمهام والأمان وقائمة الإطلاق.
