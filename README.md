# نَسَق (NASAQ) 🇸🇦

**منصة إنشاء المواقع وإدارة المشاريع بالذكاء الاصطناعي** — SaaS عربي متعدد الأنشطة: أنشئ موقع نشاطك التجاري في دقائق، وأدر المنتجات والوجبات والخدمات والحجوزات والمشاريع من لوحة تحكم واحدة تتشكل حسب نوع مشروعك، مع مساعد ذكي يساعدك على كتابة المحتوى وتحليل الأداء.

> يعمل بالكامل داخل المتصفح — لا يوجد خادم خلفي، وكل البيانات محفوظة محليًا في `localStorage`. يمكن ربطه بـ Supabase لتسجيل دخول حقيقي.

---

## المميزات

### 1. الصفحة الرئيسية (Landing)
- Hero عربي RTL كامل مع 3 أزرار إجراء ومعاينة تفاعلية للمكونات.
- **13 نوع نشاط تجاري** قابلة للنقر تفتح لوحة المشروع التجريبي المناسب.
- **27+ نشاطًا تجاريًا** مدرجًا كأقراص.
- **عارض تفاعلي** بدّل بين 5 مشاريع جاهزة لترى كيف تتغير الوحدات والمعاينة فورًا.
- **10 مميزات** للمنصة.
- **5 خطوات** لكيفية العمل.
- **عرض للذكاء الاصطناعي** مع أمثلة سياقية لكل قطاع.
- **8 قوالب** للمعاينة والاختيار.
- **3 باقات اشتراك** بأسعار توضيحية قابلة للتعديل من لوحة المالك.
- **8 أسئلة شائعة**.
- **معاينة المتجر العام** على المسار `/store/[slug]` — تعرض المنتجات أو المنيو أو الخدمات أو العقارات مع سلة شراء وصفحة هبوط مبنيّة من بيانات المشروع.

### 2. معالج الإنشاء (6 خطوات)
1. نوع النشاط (13 خيارًا أو إدخال حر)
2. معلومات المشروع (الاسم، المدينة، الهاتف، البريد، العملة، اللغة، اللون)
3. أهداف المشروع (10 أهداف تُغذّي محرك الوحدات)
4. أقسام لوحة التحكم (26 وحدة + إضافة وحدة مخصصة)
5. اختيار القالب
6. المعاينة والإنشاء — يعرض معاينة حية للموقع + ملخص المشروع

### 3. لوحة تحكم العميل — 26 وحدة
| المجموعة | الوحدات |
|---|---|
| نظرة عامة | `dashboard` |
| النشاط اليومي | `orders` · `bookings` · `quotes` · `invoices` · `delivery` |
| العروض والبيع | `products` · `menu` · `services` · `categories` · `properties` · `spareParts` · `digitalDelivery` · `stock` |
| المخزون والتشغيل | `inventory` · `vehicles` |
| العملاء والفريق | `customers` · `employees` |
| النمو والتقارير | `marketing` · `analytics` |
| الموقع والمحتوى | `content` · `portfolio` · `files` · `projects` |
| النظام | `aiAssistant` · `moduleSettings` · `settings` |

كل وحدة تدعم إضافة/تعديل/حذف مع بحث وتصفية ونماذج منبثقة (modals) وتلميحات عربية.

### 4. محرر المواقع التفاعلي
- لوحة تحكم بالـ `bld-*`: اسم الموقع، الشعار، العنوان الرئيسي والفرعي.
- إدارة الأقسام: إضافة (11 نوعًا)، إخفاء/إظهار، إعادة ترتيب، حذف، تعديل العنوان والمحتوى.
- معاينة حية بتبديل بين **سطح المكتب** و**الهاتف**.

### 5. المساعد الذكي (AI)
- يقرأ نوع نشاط المشروع الحالي ويقدّم اقتراحات سياقية.
- اقتراحات سريعة تختلف حسب النشاط (متجر / مطعم / ورشة / هندسة / عقارات / بطاقات رقمية).
- يصرّح صراحةً بأنه **وضع تجريبي محلي** لا يرسل البيانات لأي خادم.

### 6. لوحة المالك (Super Admin) — 11 قسمًا
`overview` · `subscribers` · `projects` · `plans` · `modules` · `ai` · `ai-usage` · `notifications` · `activity` · `support` · `branding`

تتضمن إدارة المشتركين والباقات والأسعار، جدول محرك الوحدات (26 وحدة مع الاعتماديات والصلاحيات والباقات)، مزودو الذكاء الاصطناعي (8 مزودين)، سجلات الاستهلاك، الإشعارات، سجل الإجراءات، تذاكر الدعم، وهوية المنصة.

## التقنيات

| الطبقة | التقنية |
|---|---|
| الواجهة | Next.js 14 (App Router) + TypeScript + Tailwind CSS |
| الاتجاه | RTL كامل + خطي Tajawal / Almarai |
| المصادقة (اختيارية) | Supabase Auth (رقم هاتف عراقي +964) |
| الاستهداف | العراق — دينار عراقي، 18 محافظة مع أجور توصيل، نطاقات .iq |
| الحالة | React Context + `localStorage` |
| التحقق | `tsc --noEmit` + GitHub Actions |
| الاستضافة | GitHub Pages (تصدير ثابت) |

## التشغيل المحلي

```bash
npm install

# اختياري — لتسجيل دخول حقيقي عبر Supabase
cp .env.example .env.local
# ثم املأ NEXT_PUBLIC_SUPABASE_URL و NEXT_PUBLIC_SUPABASE_ANON_KEY

npm run dev        # http://localhost:3000
```

---

## النشر على GitHub Pages

```bash
npm run build:static   # يكتب .env.local ثم يبني تصديرًا ثابتًا في out/
```

يُنشر تلقائيًا عبر `.github/workflows/deploy-pages.yml` عند كل `push` إلى `main`.
يعمل بلا خادم: مصادقة Supabase تعمل من المتصفح عبر المفتاح العام (`anon key`).

## قيود النموذج الأولي

- المساعد الذكي يعمل بردود مبرمجة محليًا (لا اتصال بمزود حقيقي).
- ربط النطاقات وبوابات الدفع والبريد و SMS غير مفعّلة.
- حدود الباقات والصلاحيات تُعرض في الواجهة فقط، ولا تُفرض على خادم.
- الأسعار والعملاء والطلبات بيانات تجريبية للعرض.
